§02

What it does

Frame→ Detector→ ByteTrack→ Embed + k‑means→ Homography→ Stats

Only one stage is a trained network. The rest is a motion model, an assignment algorithm, a 3×3 matrix and some clustering — which is the point worth taking from this project. Most of a computer-vision pipeline is everything around the model.

StageApproachThe interesting part
DetectionYOLO26, classes resolved by nameIndex 0 is person in COCO but ball in a soccer checkpoint
TrackingByteTrack — Kalman + Hungarian on IoUKeeps low-confidence boxes for a second matching pass, which rescues tracks through occlusion
TeamsCrop → embed → k-means, k=2Fully unsupervised. No labels, no training, milliseconds
PitchHomography from 4+ correspondencesA pitch is 105 × 68 m by regulation — the ground truth is free
StatsDistance, speed, possessionEvery one is easy to compute meaninglessly; the caveats are documented
§03

Two bugs caught before they could bite

Class indices. The original scaffold hardcoded person_class = 0. Correct for COCO, silently catastrophic with a fine-tuned soccer model where index 0 is the ball — it would track the ball as a squad of players and still emit a full set of plausible statistics. Classes are now resolved by name in class_ids_for(), which fails loudly rather than quietly detecting the wrong thing. This exact mistake invalidated the baseline in traffic-lens.

Per-frame re-embedding. Team was being recomputed for every player on every frame. A player's team doesn't change, so it's now classified once per tracker_id and cached — which removes the dominant cost under the SigLIP embedder and stops the assignment flickering between frames.

§04

Run it

pip install -r requirements.txt
jupyter lab run_all.ipynb          # or upload to Colab

Every stage in the notebook opens with an explanation of why before the code that does it. Set SOURCE in §1 to your own clip; without one it falls back to a public stand-in.

Command-line equivalent, once you have keypoints:

python src/pipeline.py --source match.mp4 --keypoints keypoints.json --imgsz 1280
